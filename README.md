## English

**NCore Control** is the official NCore application for installing and managing NANOS / nanos world servers on Windows.

### Current public release

**NCore Control 1.0.0** is the first public stable release.

For normal installation, download:

**[NCore-Control-Setup-1.0.0.exe](https://github.com/boubeur/ncore-framework/releases/download/control-v1.0.0/NCore-Control-Setup-1.0.0.exe)**

The 1.0.0 release remains hosted at the historical public distribution repository so all URLs already distributed to users remain valid.

### Main features

- install a standard NANOS / nanos world server;
- manage multiple independent server instances;
- start and stop managed servers;
- run several managed servers independently;
- create a dedicated desktop shortcut for each managed server;
- remove a selected managed server and its shortcut;
- manage NCore Control updates;
- preserve existing NANOS server files and data when NCore Control itself is uninstalled.

Automatic installation of **NCore Framework** is not enabled in NCore Control 1.0.0.

### Public/private boundary

This repository is an **official public NCore distribution and documentation surface**.

The private NCore Control development repository, internal GDDs, qualification material, build tooling and other non-public implementation material are not published here.

## Français

**NCore Control** est l'application officielle NCore destinée à installer et gérer des serveurs NANOS / nanos world sous Windows.

### Version publique actuelle

**NCore Control 1.0.0** est la première version publique stable.

Pour une installation normale, téléchargez :

**[NCore-Control-Setup-1.0.0.exe](https://github.com/boubeur/ncore-framework/releases/download/control-v1.0.0/NCore-Control-Setup-1.0.0.exe)**

La release 1.0.0 reste hébergée sur le dépôt public historique afin que toutes les URL déjà distribuées aux utilisateurs restent valides.

### Fonctions principales

- installer un serveur NANOS / nanos world standard ;
- gérer plusieurs instances serveur indépendantes ;
- démarrer et arrêter les serveurs gérés ;
- faire fonctionner plusieurs serveurs gérés indépendamment ;
- créer un raccourci Bureau dédié à chaque serveur ;
- supprimer de manière ciblée un serveur géré et son raccourci ;
- gérer les mises à jour de NCore Control ;
- conserver les fichiers et données des serveurs NANOS lors de la désinstallation de NCore Control.

L'installation automatique de **NCore Framework** n'est pas activée dans NCore Control 1.0.0.

### Frontière public / privé

Ce dépôt est une **surface officielle publique de distribution et de documentation NCore**.

Le dépôt privé de développement NCore Control, les GDD internes, les éléments de qualification, les outils de build et les autres détails d'implémentation non publics ne sont pas publiés ici.
