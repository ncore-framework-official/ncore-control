# Security Policy

NCore treats security reports separately from normal public support.

## Reporting a vulnerability

Do **not** publish an exploitable vulnerability, bypass, credential, token, private endpoint or other sensitive security information in a public GitHub issue.

Use the official NCore Discord:

https://discord.gg/Ey4dn4Cbqj

and request a private security contact channel.

When reporting a vulnerability, provide only the minimum information required to identify the affected product and version until a private channel is established.

## Politique de sécurité

Ne publiez **jamais** publiquement une vulnérabilité exploitable, un contournement, un identifiant, un token, un endpoint privé ou toute autre information de sécurité sensible.

Utilisez le Discord officiel NCore :

https://discord.gg/Ey4dn4Cbqj

et demandez un canal de contact privé pour le signalement.
